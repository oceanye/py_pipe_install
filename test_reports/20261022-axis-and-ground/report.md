# 管轴倾斜、鼠标方向误差与地面检查

本轮针对 2026-10-22 11:39 的现场评估复核算法。结论：圆柱投影和共同断面坐标本身已考虑图像内倾斜及纵深倾斜；但手画方向直接控制滤波、四条边界分别划分子段的做法确有不足，另有短亮色连接误合并两根红管的问题。已修复这些实现问题，并增加可选的双目地面距离 / 姿态检查。当前仍不能确认管间位置或安装就位。

## 几何核对

用户确认管道相对地面水平，并要求检查相机与地面的关系。相机光轴平行于地面、管轴平行于地面，也不能单独保证管轴平行于成像平面；相机朝向与管轴方位仍会影响两端深度。本轮保留自由三维轴，没有强制 `axis_z=0`。

断面中心使用 `q = Bᵀ C`，其中 `Bᵀ a = 0`，`a` 是共同管轴。沿管轴改变参考位置 `C + t a` 后，`q` 不变。因此，报告中的圆心差不应包含沿管长的平移。独立生成三维圆柱表面并投影，验证图像内 -7°、25°、-40° 及带纵深倾斜四种情况：外径 40 mm 恢复误差小于 0.02 mm；改变参考图像列、使轴心参考点沿管长移动超过 300 mm，断面中心仍一致。这组检查在修复取样前也能通过。

发现并修改：

- **方向是提示而非测量值。** 在手画方向 ±12° 内，从真实图像线段重新估计滤波方向；没有相符边缘就不生成该方向候选。当前手画线约 -4.939°，主要管道图像方向约 -7°。固定取样掩膜，仅将方向提示偏转 ±2°，左右保留边缘完全相同。
- **两眼使用共同轴向子段。** 旧实现从每条边界自己的最小像素列开始，以 128 px 交替划分，四条边界对应不同物理管段。新 `common-axial-stations-v1` 使用初始条件圆柱建立轴向坐标，取四条边界共同支持区间、共同窗口，再比较同一法向断面的圆心。坐标只用于分组，不作为实测深度；不把左右切线当成同一个表面点，不插值补遮挡。每窗至少 48 点、至少 3 窗、75% 窗口覆盖等门限保留。
- **短亮区不能连接两根完整管。** 高光连接需沿观测管轴延伸，并达到被连接候选长度的一定比例；合成的 80 px 支架亮区连接两个 740 px 红管的失败用例已恢复为两个独立候选。
- **相邻色相分箱不是不同颜色。** 允许相邻 hue 标签在实际采样颜色也接近、几何互为唯一匹配时配对；不跨不同颜色强配。蓝管右边界仍未稳定，未因修复标签就宣称蓝管量测成功。
- 橙色范围切面仍只限制样本，边缘提取剔除切面附近的人工截断，不作为圆柱真实轮廓。

版本：`image-strips-soft-axis-v5`、`pooled-sections-common-station-v2`。圆心 5 mm 一致性门限、原有三维准入、采购外径和 CAD 几何均未修改。

## 地面距离与姿态

新增 `stereo-ground-plane-check-v1`，地面选区独立于管段范围和评估分区；即使地面在管道分区外，也在原始全幅双目数据上检查一次。使用已有有效深度，鲁棒拟合平面、空间留出检查、覆盖范围检查，再用右目实际深度拟合平面交叉核对。失败时不输出确定的距离和角度。

通过后分别报告：相机到平面的垂直距离、选区相机 Z 深度中位数、光轴与地面夹角、画面相对地面横滚、稳定管轴与地面夹角。光轴在地面法线 5° 内时，地面法线在图像平面上的投影过小，横滚标记为不可可靠观测，不把未定角度输出为 0°。地面不用于强制修正管轴，也不改变安装验收状态；不使用不稳定管轴计算一个貌似可靠的夹角。

真实照片中离线选择地毯区域 `[1050,730,420,240]`，明确标记 `ASSISTANT_SUGGESTED_GROUND_NOT_CONFIRMED`，没有冒充用户确认：

- 有效深度 95.65%，抽取 4096 个实际样本。
- 同一平面支持 33.76%，空间留出支持 33.51%，低于 70% 门限；状态 `GROUND_PLANE_INCONSISTENT`。
- 没有生成可靠离地距离、光轴倾角或管轴地面夹角。当前数据不能独立验证用户所述“相机目前平行地面”，也不能据此断言相机不平行。

操作：重启 GUI → **左图框选地面** → 在左图框裸露地面，避开支架、管道、杂物 → **④ 保存并评估** → **地面距离 / 姿态检查**。紫色框为地面，橙色垂线仍为管段汇聚范围。取样范围改变会使旧结果失效；地面区域随现场保存，分辨率或标定改变会清除。拍摄导入、容差、观察方向等设置移到 **展开拍摄 / 评估设置**，避免小窗口照片区域被挤掉。
