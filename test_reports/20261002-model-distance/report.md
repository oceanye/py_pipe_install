## 新确认的阻塞原因

两种模型在同一对矫正照片下得到相同结果：

| 统计 | 左目 | 右目 |
| --- | ---: | ---: |
| 原图亮度中位数 / 255 | 11 | 21 |
| 深度有效比例 | 14.04% | 13.93% |
| 已尝试的深度候选 | 96 | 96 |
| 因预算不足跳过的深度组件 | 306 | 304 |
| 整段跳过的颜色候选来源 | 3 | 3 |
| 接受的圆柱候选 | 0 | 0 |

192 次拟合拒绝：残差过大 164 次、局部轴向支持不足 26 次、局部截面直径变化 2 次；另有 8 条预算事件。颜色候选因共享预算耗尽而没有机会运行，所以当前回放不能评价该路径能否找出三根管。

`pair_healthy=true` 只说明通过采集/基础深度健康条件；`surface_audit.truncated=true` 使 `analysis_healthy=false`，最终拒判。**这是正确的失败处理，不是管道量测成功，也不证明现场没有管道。** 远程首先检查候选来源调度和背景碎片筛选，不通过放宽残差或关闭截断拒判处理。

原始数值和拒绝原因见 [field_replay.json](field_replay.json)。

## 模型、标定与弱光证据

- [model_mapping.json](model_mapping.json)：实际 12 个 STL / DXF 管位的逐一映射；两者管号不同。现场总数 3 已确认，具体模型实例仍不明确。
- [calibration_check.json](calibration_check.json)：沿用 `field-chess-fb5dc0f71ee5`。当前 6 对固定姿态图像的格边长中位数 17.01–17.07 mm，角点深度中位数 1290.11–1290.94 mm，垂直残差 P95 2.10–2.23 px。这是局部棋盘检查，不是全视场或管道距离精度认证。
- [low_light_comparison.json](low_light_comparison.json)：既有 6 帧逐配置汇总。原始灰度 256 px 与 NLM+CLAHE 比较：全图有效深度 9.37% → 14.07%，蓝管左区域 2.11% → 3.16%，棋盘参考错配比例 80.34% → 34.82%。仍不足以可靠量测。棋盘参考来自稀疏角点视差平面，不是独立距离真值；这些比较不是本轮新增白天采集。

距离输出现在区分中心线、该截面的最近表面、侧面轮廓切点，以及 Z / 空间距离；定义和公式见 [管道模型尺寸与距离定义](../../doc/管道模型尺寸与距离定义.md)。

## 复现范围与后续验收

仓库合成/单元回归可在远程直接运行 `python -m pytest tests -q`。真实回放使用的模型、原片、矫正照片、标定、manifest 和报告索引见 [inputs.json](inputs.json)，均含 SHA-256。标为 `LOCAL_ONLY` 的内容没有上传；仅有这份报告不能在远程重放实际照片。旧 `field_reports/latest.json` 不指向本轮数据。

后续验收由本机负责：白天持续预览与开关相机、多档快门请求/实际值、同一对照片的模式对比、每管有效点和圆柱拟合、明确参照点的独立距离检查。远程按 handoff 开发并回传提交，测试失败项继续保留并汇报，不以软件测试数量替代现场验收。
