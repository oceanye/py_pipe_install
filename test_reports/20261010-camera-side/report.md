# 相机观察侧 GUI 与配准验证

日期：2026-10-10。基线：`7421fa5`，已包含颜色与反光 GUI（PR #14 已合并、Windows/Ubuntu CI 通过）。本轮分支 `feature/elevation-camera-side`。

## 改动与数据约定

- 将模型共同管长轴和相机观察侧分开。GUI 提供自动判断、从 ±X/±Y/±Z 六侧观察，模型预览显示正向坐标轴及朝向/背向屏幕提示。
- `registration.camera_side_world` 保存模型朝相机观察侧的单位向量；缺失或 `null` 为自动判断。改变方向清除旧结果并断开历史；换模型重置。预览旋转不写入设置，过期预览不可覆盖新配置。
- 候选旋转 `R` 为模型到左目矫正相机，筛选条件 `-(R @ camera_side_world)[2] > 1e-6`。方向只限制观察半空间，不指定相机平移、滚转角或精确倾角。保留全部观测数、非共线、直径、残差、搜索上限与状态证据要求。
- 报告保存 `camera_view` 策略与拒绝候选次数；解出的 `estimated_camera_side_world` 是光轴反方向，不是绝对相机位置。全幅/分区均生效。

## 现场边界与交接

这轮没有重新采集物理相机、重新标定或验证现场管道直径/距离。旧 2026-10-08 四管照片仅用于检查真实 GUI 载入；现场相机与模型轴的对应关系没有得到独立确认，所以默认保留自动判断。

操作员应先核对模型坐标：圆形 DXF 管长沿 Z，±Z 为端面观察，±X/±Y 为侧面观察；STL 以文件实际轴为准。可选方向并不保证唯一身份，观察不足或对称排列仍需补足几何证据。原有颜色与反光检查继续独立用于拍摄调整。

不使用新约束时，将观察侧切回自动判断即可；它会按配置改变重新开始历史。若需要回退软件，先在当前版本保存为自动判断，使新字段省略，再用旧版本打开该包；旧版本不识别包含 `camera_side_world` 的新配置。代码通过本轮 PR 提交，可整体回退。
