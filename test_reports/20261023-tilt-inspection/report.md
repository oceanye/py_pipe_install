# 倾角检查与地面涂色

用户确认机位角度固定，要求将倾角检查做成独立功能，在图面显示角度及被识别为地面的具体区域。本轮实现独立计算入口、真实支持像素涂色、单独地面预览和可追溯报告；没有放宽地面通过门限。

## GUI 使用

1. ③双目抓拍，或载入同一次拍摄的左右矫正图；确认同步照片。
2. 点击 **左图框选地面**，选实际裸露地面，避开管道、支架、瓶子。紫框只是搜索范围；相机固定时可沿用选区。
3. 点击 **倾角检查**。无需 CAD；只计算当前一对照片的双目深度和地面平面，约 5 秒。结果显示在左图，并打开无管道标注遮挡的独立地面预览。
4. 绿色为通过双目平面检查、且由操作者指定地面的支持像素；橙色为未通过或尚未确认的候选。无有效深度、偏离平面的物体不会被补色。没有可解平面时显示“倾角暂无有效解”，不写成 0°。
5. 如需将合格地面用于管道断面重算，点击 **④保存并评估**，再用 **地面修正** 查看应用情况。单独检查保留已有管道报告，不宣称已重算管径或完成安装验收。

图上标注光轴与地面的无符号夹角（0° 平行、90° 垂直）和画面横滚角。接近垂直俯视时横滚不可可靠观测；暂用标定明确提示角度精度未验证。失败平面的数字只标作候选，不进入修正。一般后墙不能直接当作地面；角度含义依赖选区确实为地面。

更换照片、标定、选区或评估输入后，旧角度/涂色及独立预览失效，需重新检查。独立检查是当前一对照片；完整评估仍按已有规则使用多帧深度，两者数据范围有明确区分。

## 实现与证据

- `ground_check.py` 升为 `stereo-ground-plane-check-v2`，保留失败平面假设供诊断，原通过门限和地面修正规则不变。
- 涂色按全选区每个实际左目有效深度计算到候选/通过平面的距离，容差 5 mm。不是将抽样点外推成整块地面，不做闭运算或空洞填充。保存 ROI 掩膜、像素计数及坐标系，采用无损位打包压缩；读取检查尺寸和数据长度。
- GUI 缩放、平移使用相同坐标变换，掩膜最近邻重采样；原图不修改。主界面保持紧凑角度标签，独立预览显示纯地面涂色，结果文字支持滚动。
- 独立计算检查照片哈希、同步时间、标定/图像尺寸及拍摄质量；后台运行、按输入代次丢弃过期结果。不打开相机，不要求模型。
- 独立报告保存在 `outputs/elevation_workbench/ground_inspections/tilt-*/inspection.json`，同目录 `left_ground_overlay.png`；包含照片路径/哈希/时间、标定副本、分析配置、深度审计及支持掩膜。完整评估报告与最新左目证据图也包含涂色和角度。
