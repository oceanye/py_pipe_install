# GUI 管长方向与两条汇聚边界

用户要求在 GUI 指定管长方向，并以两条垂线限定管段汇聚范围。已接入左目图交互、现场保存和正式全幅/分区评估；不需要手工修改 JSON。

## 使用方法

1. 重启 GUI，抓拍或打开已保存的现场。
2. 点击 **管长方向 / 汇聚范围**，在左图沿管长拖一条方向线。两个端点各生成一条橙色垂线，两条垂线之间的浅青色区域就是左目汇聚范围。
3. 拖动橙色端点，边界会沿已指定方向移动，方向保持不变。需要改方向时，再点按钮重新画线。Esc 取消本次绘制，**清除汇聚范围** 恢复自动汇聚。
4. 点击 **④ 保存并评估**。在 **管段汇聚** 查看范围及边界质量，在 **断面尺寸与就位** 查看后续结果。

建议选在支架之间，保留至少约 384 个原图像素的轴向范围；小于该范围允许保存，但可能不足以做子段稳定性检查。管数不需要预先指定；同一对垂线约束范围内所有可见平行管段。已有矩形评估区域与本范围取交集。

图像方向不是模型 `axis_world`，也不是已知毫米长度或三维方向；后者仍须通过双目解算。当前汇聚后端仍使用 `y=f(x)` 的图像边缘参数化，接近竖直的管道会报告 `AXIAL_IMAGE_PARAMETERIZATION_UNSUPPORTED`，不会因为画了方向线而自动获得合格三维尺寸。

## 取样与保存

- 配置保存在 `analysis.elevation_auto.registration.aggregation_band`，版本 `left-image-axial-band-v1`，包含左目矫正图尺寸及两个原图像素端点。没有本字段的旧现场仍使用自动汇聚。
- 端点和垂线按原图坐标计算，缩放和平移不改变选区。端点不能互相越过或越出图像；最小间隔 32 px。
- 左目在候选提取前切断范围外连接，再从原始像素提取边缘。切线附近可能产生的人工上下边界被排除，范围外样本不会进入左目汇聚。没有补遮挡轮廓或深度。
- 右目根据实际匹配器的最小视差、搜索宽度和主点偏移建立搜索包络；分区恢复原图偏移后计算。右目包络是可能对应区，不是已经确定的逐像素对应，也不与左图橙线机械重合。
- 改范围会清除旧评估显示，并使旧范围的历史不再兼容；保存重开恢复范围。更换标定或图像分辨率清除范围。同尺寸固定机位再拍可保留范围，机位改变后应重画。
- 稠密深度仍按原有全幅/分区流程计算；新增范围控制管段边界汇聚阶段。二维选区不会替代尺寸、标定或模型对应检查。
