# 将地面检查接入实际修正

用户明确要求“改成地面修正”。本轮将地面平面接到正式管段汇聚和断面求解之前：地面证据通过后，以用户已确认的“管道平行于地面”为约束重新求解三维管轴，再重新拟合管径、断面圆心和管间相对关系。不是仅更名按钮，也不是旋转展示图片。

## 修正方法和生效条件

新增 `ground-constrained-pipe-axis-v1`；断面阶段版本升级为 `pooled-sections-ground-constrained-v3`。从实测地面法向 `n` 构造平面内二维基底 `B`，满足 `nᵀB=0`，再将左右真实边缘的反投影平面法向矩阵 `N` 限制到 `N B`，求取最小残差的单位管轴。这样 `n·a=0`，但不要求 `a_z=0`：相机斜视时，同一水平管两端仍可存在深度差。

该解重新进入自由半径拟合、共同轴向取样、子段一致性及相对就位评估，保留 `unconstrained_axis` 供比较。未修改相机内参、基线、原始深度或采购 / CAD 外径。误差审计明确标记地面法向不确定性尚未计入像素误差传播，修正成功不代表总精度已验证。

必须满足：

- 明确框选实际地面，且已有双目平面、空间留出、覆盖与两眼一致性检查全部通过。原来的质量门限未降低。
- 至少三条可用边界且同时有左右目支持；遮挡 / 多管外包络候选不参与确定管轴。
- 平面内方向可解，奇异值比不超过 0.25；修正轴对应的每条实际图像边缘 P95 残差不超过 2 px。该检查使用有限图像上的真实边缘，不以无限远消失点的角度残差替代。

地面未设置、检查未通过、选区尚为助手建议或轴向不可解时，保留自由轴向结果并记录原因。如果地面支持充分但“水平管”约束与图像边界冲突，保留原解供诊断，同时给断面候选增加 `GROUND_AXIS_CONFLICT`，不据此判断安装就位。

全幅和分区均先在全幅图上拟合地面一次；分区裁剪只改变内参中的像素原点，不旋转相机坐标中的地面法向。地面可以位于管道分区外。最终报告区分全部应用、部分分区应用、未应用。修正后管轴与地面约为 0° 是约束结果，GUI 明确说明它不是独立核验。

## GUI 使用

重启 GUI → **左图框选地面** → 框裸露地面，避开支架和管道 → **④ 保存并评估** → **地面修正**。

新版“地面修正”窗口说明每个分区是否应用修正、方向变化及未应用原因；通过后仍可查看离地距离和相机姿态。清除地面区域后，重新评估恢复自由轴向。历史仅检查地面的报告不会被误显示成已经修正，需要重新评估。
