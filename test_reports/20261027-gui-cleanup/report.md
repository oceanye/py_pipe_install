# 2026-10-27 GUI 功能检查与简化

默认启动已改为直接进入管道安装分析。现场界面常驻按钮/菜单从 25 项减少到 12 项，模型入口和分析详情分别合并，低频参数移至独立设置窗口。求解算法、标定、数据格式和状态门限未改动。

| 功能 | 检查发现及处理 | 验证 |
| --- | --- | --- |

| 标定 | 载入与重新标定合并为菜单，主界面短状态，完整信息移入照片设置 | 打开向导、暂用标定提示、相机互斥及标定改变清理测试 |

| 地面倾角 | 原“地面修正”只读报告容易误解；新入口打开设置，明确区分框选、检查、查看结果和④重算 | 设置四页布局、地面试验保存恢复、完整评估实际重算 |
| 求解参数 | 深度/弱光、辅助算法、匹配容差、颜色筛选放在求解参数页 | 控件绑定、忙碌禁用、配置回归 |
| 颜色与反光 | 独立检查保留；模型颜色编辑只在 CAD 表出现 | 实际窗口可打开；框选、取色、显式应用、照片失效回归 |
| 状态分析 | 现场求解与 CAD 安装保留两个分页；默认四行并支持滚动 | 四根实物行可见、选择联动、输入失效清空 |
| 分析详情 | 五个入口合并成五页：候选、断面汇聚、地面、CAD、识别诊断 | 选择更新现有详情，输入改变关闭旧详情；CAD 双击也查看详情 |
| 照片、历史、分区、日志 | 保留在设置/菜单，降低主界面密度 | 现场保存重开、历史兼容和日志回归 |
| 小窗口 | 长路径/诊断原先推挤图片；状态文本固定高度、可滚动复制，设置窗口不占图片区域 | 实际 Tk 几何测量，长文本测试 |
