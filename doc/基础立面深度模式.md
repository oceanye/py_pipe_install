# 基础立面深度模式

基础模式用于“每根连续管道只有一个安装状态”的现场场景。它不使用 STL 三角网格到相机的三维投影，也不要求二维码 CAD 配准；左右图仍必须是同一标定尺寸、同一矫正坐标和同步的一组照片。双目深度用于确认前后关系和可见性，颜色区域用于管道身份候选。

基础模式的入口仍是现有 `analyze-stereo`，只需把 manifest 的 `analysis.mode` 设为 `elevation_depth`。这种模式的 `analysis.elevation_depth.pipes` 为每根管提供两个左右图像区域：

```json
{
  "analysis": {
    "mode": "elevation_depth",
    "elevation_depth": {
      "minimum_color_support_fraction": 0.10,
      "minimum_valid_depth_fraction": 0.25,
      "minimum_negative_captures": 2,
      "pipes": [
        {
          "pipe_id": "P001",
          "color_srgb": "#E74C3C",
          "nominal_diameter_mm": 22,
          "left_region_px": [120, 80, 180, 80],
          "right_region_px": [118, 80, 180, 80]
        }
      ]
    }
  }
}
```

现场包仍保留最小可追溯信息：`stereo_calibration`、`capture` 中的左右图路径/哈希/尺寸/时间、以及管道 ID、颜色、直径和图像区域。可以省略 CAD 文件、CAD 对象 GUID、二维码设置、姿态微调和局部三维测量记录。图像区域必须来自同一固定立面和同一分辨率；它不是任意拖框后就能保证身份正确的工具。

状态规则如下：

- `INSTALLED`：当前左右目都检测到目标颜色，且区域内有足够有效双目深度。
- `NOT_INSTALLED`：至少两次不同照片组都显示区域可见、深度有效且目标颜色缺失；相同文件哈希不会重复计数。
- `UNKNOWN`：遮挡、无效视差、深度不足、配对不健康，或者同色区域重叠导致身份不能唯一确定。

模式报告明确写入 `registration_required=false`、`assignment_method=color_diameter_depth_component` 和 `production_authority=false`。它是立面筛查，不提供未经验证的毫米级 CAD 定位，也不能解决同色同径管道的身份歧义。若需要从 STL 自动生成图像区域，必须先增加一次轻量的立面基准线/两点映射；不能把未验证的相机姿态当作三维注册。

核心实现位于 `pipe_twin/elevation_depth.py`，完整三维 CAD/二维码路径保持不变。回归测试覆盖安装、重复空场、无效深度、重复哈希、重复管 ID 和同色重叠区域。
