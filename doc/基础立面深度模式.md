# 基础立面自动匹配

适用于一组平行直管、同一根管沿长度只有一个安装状态的场景。程序从校准后的双目照片重建可见局部管面，匹配 STL 中的管径与截面排列，在左右图中自动定位每根管道，输出“安装 / 未安装 / 遮蔽不确定”。不需要先为每根管分别框选左右图，也不需要二维码。

## 第一次使用

1. 双击 `run_gui.bat`，点击 **基础立面评估**，保持默认自动模式。
2. 选择 STL 原始单位，再点击 **① 导入 STL**。核对识别的独立直管组件及外径；双击管道行设置展示颜色，**同径统一颜色** 可批量应用。自动模式的管径和中心线来自实际 STL，不手工改写几何。
3. 点击 **② 相机标定**，载入真实标定包；没有可用标定时使用 **自动标定向导**。标定完成后即可抓拍，不要求 QR 世界坐标配准。
4. 点击 **③ 双目抓拍**。通过向导生成的标定会自动矫正照片。也可导入同一次同步拍摄的左右已矫正图，核对同步与拍摄时间。
5. 点击 **④ 保存并评估**。程序计算双目深度、拟合局部圆柱、搜索 STL 截面对应，自动显示逐管结果及检查区域。

STL 不保存单位、颜色或业务编号。相接、共享顶点的多个实体可能被合并成一个组件；弯管、非圆形件或无法提取独立轴线的组件不属于当前直管目录，需要先修正模型。

## 摄像头斜着看时如何处理

程序使用带实际毫米尺度的三维深度，不要求镜头与建模立面平行。模型轴线给出管长方向，现场圆柱拟合给出相机坐标中的管轴，匹配在垂直于管轴的截面平面中完成。

默认从 STL 自动识别共同管长方向。可打开 **设置管长方向**，旋转模型，选择同一根中心线的两个端点，或输入 STL 坐标中的向量。指定方向只减少方向解释的不确定性，不能补出照片中没有观测到的管道身份。向量并不是相机外参，也不要求填写长度方向上的绝对位置。

局部点云与模型在匹配后叠加预览；长度方向的平移仅用于显示对齐，不代表测出了管道起点或施工分段。当前状态按用户的“整根管沿长相通”假设聚合，不评估沿长度不同位置的施工进度。

## 匹配有歧义时

当前默认要求足够的非共线截面观测来验证布局；只有一两根可见、所有可见管落在一条截面直线上，或同径管形成重复排列时，可能有多个成立的匹配。程序保留不确定，并在报告中列出原因及备选对应。

这时先查看局部观测编号，再指定少量“局部观测 → STL 管道”基准对应。对应只对当前照片有效，更换照片后清除，避免把上次的观测编号误用于新画面。两条对应不一定能排除镜像歧义；若仍不唯一，应调整视角，让更多有区分度的管道进入画面。指定管长方向本身不能解决重复布局的身份歧义。

颜色可用于展示和生成额外的候选区域，自动匹配的身份依据是实测圆柱几何和整体排列；不要求实物必须涂成 STL 展示色。深度不能支持圆柱拟合时不会用模型半径填补“实测”点云。

## 三种状态的依据

| 状态 | 所需证据 |
|---|---|
| 安装 | 当前采集健康，左右目各自拟合的局部圆柱一致，并在唯一的 STL 布局匹配中得到对应。 |
| 未安装 | 布局匹配可信，目标预期管面后方在左右目均有足够有效深度，前景遮挡很少；至少两次连续独立采集都支持该空位。 |
| 遮蔽不确定 | 无法唯一匹配、未形成可用局部圆柱、视野外、遮挡、深度不足、采集不健康或空位证据尚未重复。 |

自动模式按每个像素的圆柱前表面计算预期深度，适应斜视带来的深度渐变；不需要人工填写每根管的参考深度。只在匹配管道实际共同可见的轴向范围内检查空位，避免用无法观测的 STL 端点推测施工位置。

两次空位证据须间隔至少 1 秒且照片像素不同；仅换文件名、时间戳或再次分析同图不累计证据。相机对齐变化、当前遮挡或匹配失败会中断空位证据。仅仅“没有识别到管道”不能证明未安装。

## 重复使用与现场数据

恢复上次现场，或点击 **打开基础现场** 选择 `manifest.json`，核对机位后 **抓拍 → 保存并评估**。模型、管径颜色、标定和方向设置可以复用。更换模型、标定、模式或匹配配置时自动开始新历史；输入改变后清除旧结果。

默认保存至 `outputs/elevation_workbench/captures/<采集编号>/`：

- `manifest.json`：`analysis.mode=elevation_auto`，模型绑定的完整管道目录、方向与可选基准对应、标定、照片尺寸/哈希/同步时间。自动模式不需要逐管 ROI 或参考深度字段。
- `model/`：参与匹配的实际 STL；读取时复查哈希、组件、外径和中心线。
- `photos/`、可选 `history/`：当前及连续证据的左右照片；矫正配方也随包保存。
- `report.json`：逐管状态、匹配结果/歧义、局部圆柱拟合审计、每组采集的深度与空位证据。
- `evidence/`：左右匹配叠图和 `local_surface.ply` 局部点云，坐标为左目矫正相机坐标、单位毫米。

复制整个目录即可在远程主机重算：

```powershell
python -m pipe_twin analyze-stereo --manifest "现场目录/manifest.json" --output "现场目录/report.json" --evidence-dir "现场目录/evidence"
```

## 旧现场兼容

`elevation_depth` 现场仍用手工兼容模式打开，保留逐管左右 ROI、参考深度和历史逻辑。切换为自动模式需要导入实际 STL；原有手工 ROI 不会被当作自动三维配准证据。完整 CAD/二维码模式的外参要求不变。

## 验证范围

软件回归覆盖斜视圆柱的实际几何反投影、左右配对、局部与完整布局匹配、歧义拒绝、空位/遮挡/重复历史、现场包与真实 OpenCV 视差入口。合成回归不等于现场相机精度验收。

当前上传的旧现场素材仍有标定与深度质量问题，详见 [实测复算评估](FIELD-20260911-实测素材与标定复算评估.md)。光滑、反光或无纹理管面可能无法形成足够有效视差，此时结果会保持不确定；需要合格标定与现场照片验证自动拟合能否稳定工作。基础模式不输出毫米级生产验收结论。

```powershell
python -m pytest -q tests/test_local_surface.py tests/test_elevation_registration.py tests/test_elevation_auto.py tests/test_elevation_dataset.py tests/test_elevation_gui.py
```

实现的坐标约定与 OpenCV [stereoRectify / reprojectImageTo3D 文档](https://docs.opencv.org/4.8.0/d9/d0c/group__calib3d.html) 一致：使用矫正后的内参与第一相机坐标，双目尺度来自标定基线。
