# 基础立面深度模式

适用于固定双目机位、同一根直管沿长度方向只有一个安装状态的场景。每根管输出“安装 / 未安装 / 遮蔽不确定”，不区分沿长度的分段施工进度。STL 提供管道目录、编号和设计外径；左右照片中的区域建立现场对应关系，不需要二维码或 CAD 三维姿态配准。

## 第一次使用

1. 双击 `run_gui.bat`，点击左上角 **基础立面评估**。也可运行 `python -m pipe_twin gui`。
2. 选择 STL 的原始单位，再点击 **① 导入 STL**。核对自动识别的独立直管组件；点击 **查看模型管道编号** 可查看沿共同长度轴观察的编号布局。
3. 双击管道行，修改设计外径和目标颜色。选中一根管点击 **同径统一颜色**，即可将该颜色应用到相同管径。颜色应接近现场照片中管道的实际颜色。
4. 点击 **② 相机标定** 选择真实标定 JSON 或导出的标定包；没有可用标定时使用 **自动标定向导**。基础模式标定结束后直接抓拍，不要求二维码定位。演示标定不能用于此入口。
5. 点击 **③ 双目抓拍**。棋盘格向导生成的标定会使用配套参数自动矫正照片。也可以导入同一次同步拍摄的左右**已矫正图**，并核对拍摄时间；两个独立设备仍需核对硬件同步。
6. 在表格中选择管道，在左、右图各拖一个框，分别对应同一根管道的位置。框内应有足够长的管段及少量边缘背景，避免把邻管一起框入；滚轮缩放、右键平移。首次每根管需要两个区域，之后固定机位可复用。
7. 核对同步、机位和区域位置，勾选确认，点击 **④ 保存并评估**。结果直接显示在左右图和逐管表格中。

STL 没有业务编号、颜色和单位。相接或共享顶点的网格可能合并为一个组件，必须核对导入目录。基础模式目前不会从 STL 自动推算照片区域。

## 如何判定“未安装”

目标颜色缺失不能证明没有安装：也可能被遮挡。因此，“未安装”还需要该管道的**参考表面深度**。

- 管道可见时，先完成一次“安装”识别，选中该管点击 **记住当前有效深度**，再保存现场。
- 管道尚未安装时，可双击该管填写已知的预期表面深度，单位毫米；它是从左目相机沿光轴到预期管道表面的深度，不是沿管长的距离，也不是任意斜距。
- 不填写参考深度仍可识别可见的安装管道；颜色缺失时保持“不确定”。

判定“未安装”需要当前及之前连续至少两组独立照片，间隔至少 1 秒，均显示预期位置后方有足够有效深度、目标颜色缺失且无明显前景遮挡。相同照片重复分析不会累计证据；中间出现安装、遮挡或无效采集会中断连续空位证据。

## 固定机位下重复使用

再次打开基础界面会恢复上次保存的现场。也可点击 **打开基础现场**，选择保存目录中的 `manifest.json`。恢复后核对机位，直接 **抓拍 → 保存并评估** 即可；默认沿用区域和历史，不需要重新导入 STL。

相机移动后应关闭“沿用上次场景历史”，重新框选并重新建立参考深度。更换标定会清除旧照片、区域和参考深度；更换照片尺寸会清除对应区域。修改管道配置、模型或标定后会自动开始新历史，旧结果随输入变化立即清除。

## 现场包与报告

默认保存到 `outputs/elevation_workbench/captures/<采集编号>/`，包含：

- `manifest.json`：管道编号、颜色、外径、左右区域、可选参考深度、相机标定，以及照片尺寸、哈希和时间；棋盘格矫正参数也随包保存。
- `photos/`、可选 `history/`：本次及用于分析的历史左右照片。
- 可选 `model/`：STL 原文件，仅用于恢复目录和核对编号，不参与未经配准的三维投影。
- `report.json`、`evidence/`：逐管状态、门槛检查、每次采集证据和左右叠图。

复制整个采集目录即可在另一台电脑重开或分析；无需准备 QR、CAD 姿态、三维测点或手工编辑 JSON。相机设备编号是机器设置，换电脑后需要重新选择设备。

命令行重算：

```powershell
python -m pipe_twin analyze-stereo --manifest "现场目录/manifest.json" --output "现场目录/report.json" --evidence-dir "现场目录/evidence"
```

## 判定与验证范围

“安装”要求左右目同一长条颜色组件上有有效深度，管径投影宽度、左右位置/视差及深度一致；有参考深度时还必须匹配参考。遮挡、无效深度、照片质量不足或同色区域严重重叠均保留“不确定”。

该模式是立面状态筛查，不提供毫米级 CAD 定位或生产验收结论。短管、弯管、斜向很大的投影、无纹理表面以及同色背景仍需现场评估；框选本身不能证明身份正确。需要准确三维节点和基向量时使用完整 CAD/二维码模式。

回归命令：

```powershell
python -m pytest -q tests/test_elevation_depth.py tests/test_elevation_dataset.py tests/test_elevation_gui.py
```

测试覆盖真实 OpenCV 视差计算的合成立体照片、保存/恢复现场、GUI 交互、重复证据及遮挡判断。合成测试验证软件链路；真实相机标定精度、材质和照明条件仍需现场实测。
