# 局部测量工作台

双击仓库根目录的 `run_gui.bat` 即可启动，也可以运行：

```powershell
.\.venv\Scripts\python.exe -m pipe_twin gui
```

界面默认空白，点击“打开合成示例”熟悉操作，再点击“运行双目识别与测量”。示例是合成数据，不代表真实管件或相机的验收结果。

## 工作台配置档案：一次配置，开机自动恢复

现场数据录入中的模型、管件目录（业务 ID、外径、颜色、设计层）、双目标定（含二维码定位和相机方向修正结果）、二维码打印参数、相机设备索引、抓拍选项和最近一次清单，会自动保存到 `outputs/measurement_workbench/workbench_profile.json`（每次保存前自动轮换一份 `.bak`）。下次启动软件时会自动恢复上次清单和全部配置；如果配置文件损坏，启动时会自动隔离为 `workbench_profile_recovery_*.json` 并按未配置状态启动，不会阻塞软件。

- “保存全部配置”在“现场数据录入”窗口中，可随时手动保存；“重置配置”会先确认，再将当前档案移为恢复文件并写回空档案。“保存标定结果”会另存一个便携 JSON，同时包含双目标定、原始帧极线矫正配方、二维码实测尺寸和 CAD 位姿；下次可点“读取标定结果”完整恢复。
- 二维码定位中的“已复核打印尺寸”“已确认 CAD 坐标方向”两项安全勾选**不会**被保存，每次打开仍需人工重新勾选。
- 保留历史拍摄组的配置一致性（同一模型哈希、管件目录、标定）由档案自动保证，跨天累积“未安装”证据不再依赖手工重填。

## 棋盘格双目标定向导：不再依赖外部标定文件

点击工具栏“棋盘格标定向导”（或在“现场数据录入”中点击同名按钮），无需先载入清单：

1. 点击“生成 A4 棋盘格打印 PNG”，按 100%/实际大小打印（禁止“适合页面”），用量具测量打印后的格边长，填入“打印后实测格边长”。
2. 点击“检测设备”自动填写设备索引并探测相机支持的流分辨率（下拉框可随时手动更换）。程序优先选择实际可用、每目为横向画面的最高分辨率；当前相机应优先使用 `3840×1080（每目 1920×1080）`，避免以缩放后的 `2560×720（每目 1280×720）` 标定。确认“每目宽×高”后点击“打开预览”。预览会实时标注棋盘格角点检出状态。
3. 勾选“连续抓拍”（默认勾选）后，**只要左右目同时检出棋盘格且位置相对上一组有明显移动，就自动接受一组**，不用逐次点击按钮；“抓拍一组”按钮仍可手动补拍。移动棋盘格时请覆盖：
   - **画面区域**：左上、右上、中心、左下、右下都要经过（求解门禁要求 ≥6 个不同区域）；
   - **远近**：至少 2～3 个距离，例如最终测量距离约 1 米时，在 0.5 / 0.8 / 1.2 米各拍几组——棋盘格太远导致角点太小无法检出时说明超出有效距离；
   - **倾斜**：每个区域配 ±10°～30° 的俯仰/偏转，避免全是正对。
   建议总数不少于 10 组。
4. 点击“完成标定并保存”。程序自动完成左右目内参/畸变标定、双目联合标定和极线矫正，显示各项重投影 RMS 与基线；全部门禁通过后才会保存。
5. 保存内容为：`outputs/measurement_workbench/calibration_current.json`（清单格式，自动选中）+ 工作台档案中的极线矫正配方。**向导只解决相机内参与极线矫正，不解决 CAD 配准**——保存后请再做一次“二维码定位”（或设置相机方向），然后保存工作台配置；此后无需重复。

向导产生的标定描述的是矫正后的双目刚体；抓拍时程序会用档案中的矫正配方把相机原始帧实时转换为矫正图。配方丢失或与标定不匹配时会明确报错，不会用错误内参继续分析。

标定未通过时点击向导内或现场录入页的“完整日志”。默认显示 `pipe_twin.calibration_wizard` 和 `pipe_twin.qr_registration` 的全部结构化记录，可取消筛选查看整个程序日志；日志路径为 `logs/pipe_twin.log.jsonl`。门禁报告会记录左右/双目 RMS、焦距、主点、基线、画面区域、内角点规格、实测格边长和完整求解审计。

## 从照片取色

在“现场数据录入”的管件目录中选择一根管件，点击“从照片取色”，再点击左目照片上的管件表面，程序取 9×9 像素中值颜色写入该管件并保存到档案。取色来源就是分析所用照片，与颜色门禁输入一致。颜色可区分的管件各配一次即可。

## 输入现场数据

模型可选择 3DM、3MF 或 STL。STL 先选择原坐标单位，再读取直管目录；选择标定 JSON 后，可点击“相机方向/倾斜校正”设置相机所在方向、双目组中心和 yaw/pitch/roll。改变外参后，应以固定控制点复核并登记验证状态。

已有完整清单时，点击“载入清单”。“现场数据录入”已整理为四组：CAD 模型、双目相机与定位、管件目录、创建现场数据。历史左右照片与拍摄时间默认收起；直接连接相机时会自动填写。首次配置后，日常采集只需“连接相机并同步抓拍 → 创建现场数据并载入 → 运行双目识别与测量”，或直接点工具栏“一键抓拍并分析”：

1. 选择 3DM/3MF/STL 模型，点击“从模型读取直管目录”。STL 还必须先选择原坐标单位。检查所有目标管件是否都在表内；双击可修改业务 ID、设计外径、颜色和设计层，颜色也可以选中管件后点“从照片取色”直接从抓拍照片上取色。辅助对象及不能可靠识别的非直管会列为未纳入对象，也可以导入已有清单的管件目录。
2. 双目标定可以来自外部 JSON（选择带 `stereo_calibration` 的完整清单或该对象本身；点击“导出标定格式示例”可获得字段示例），也可以点击“棋盘格标定向导”由软件自动生成（见上一节）。连接 USB 相机时会拒绝 ID 含 `SYNTHETIC`、`DEMO`、`EXAMPLE` 的演示标定，以及尚未验证或未声明极线校正的标定，防止把合成参数误用于现场测量。
3. 首次使用推荐点击“二维码定位”，生成默认编码区边长 120 mm 的 A4、300 DPI PNG。打印时选择 100%/实际大小，禁止“适合页面”；用量具检查页面上的 100 mm 校验线，并测量二维码**编码区外框**边长。界面的“文件标称边长”保持生成文件时的 120 mm；若打印后量得 114.5 mm，就在“打印后实测边长”填写 114.5，程序会按实测尺寸解算距离，无需重新打印。将纸张贴平，登记二维码中心的 CAD 坐标，并按打印页箭头选择纸面 RIGHT、UP 对应的 CAD 方向。二维码定位结果随档案保存，之后无需重复。
4. 相机已连接时点击“连接双目相机抓拍”。设备索引和采集方式从档案带出，分辨率自动取标定文件每目宽度的两倍；在实时左右预览中核对镜头顺序，也可切换“右 | 左”或两个独立相机。若当前标定来自棋盘格向导，程序会自动用矫正配方把原始帧转换为矫正图后再保存。点击“同步抓拍并使用”后，程序自动保存左右 PNG、主机时间、设备索引和同步方式；来自同一并排帧时自动确认配对，不需要手工填写四项照片/时间字段。
5. 二维码出现在左目抓拍图中后，再次点击“二维码定位”。核对文件标称边长，填写打印后量具实测边长、中心 CAD 坐标和纸面方向，勾选两项现场确认，然后点击“识别当前左目图并应用定位”。界面显示相机到二维码距离、角点重投影 RMS、双目中心 CAD 坐标和观察方向。固定相机后可移走二维码，再同步抓拍一次管件；二维码定位结果会保留。
6. 相机已经通过现场摆放大致对正时，点击“相机方向/倾斜校正”，再直接点击“一键自动微调角度”；程序沿用当前位姿，从彩色管件长边估计 ±20° 内的画面滚转并填写修正值。通常不需要填写方向和坐标；只有需要重新做粗定位时，才展开“可选方向与高级参数”，选择从上往下、从下往上、从左往右或从右往左。yaw/pitch 无法由单组平行管轴唯一确定，需要使用二维码完整位姿或固定控制点验证。
7. 已有照片回放时仍可直接选择左右照片。选择后会自动带入照片文件修改时间，请核对并按需要改成实际曝光时间。可输入 `2026-09-07 15:30:20`、`2026/9/7 15:30`、中文年月日或完整 ISO 时间；未写时区时使用本机时区。仅填日期不够，左右目还必须满足标定文件的同步时间差。程序校验照片尺寸、标定、时间差及文件内容，不从文件名猜配对关系。
8. 点击“创建现场数据并载入”。程序在 `outputs/measurement_workbench/captures/` 创建独立数据包，保存相机图、模型、二维码定位审计和清单。原文件保持可用。
9. 点击“运行双目识别与测量”。同一模型、管件目录和相机配置下，下一次拍摄可勾选“保留历史”，积累连续缺失的证据。

工具栏“一键抓拍并分析”把第 4、8、9 步合并：从档案读取模型、标定、矫正配方、相机设备和历史选项，打开实时预览，点击“抓拍并分析”即完成抓拍、数据包创建和识别。任何门禁失败都会显示原始原因并退回完整的“现场数据录入”窗口，不会跳过校验。

当前分析入口要求输入为**已做极线矫正的左右图**，并提供相应的共同内参、毫米基线和相机在 CAD 世界坐标中的位姿。`validated` 表示相机标定已确认，`registration_validated` 表示 CAD 与相机配准已确认，两者分别校验。棋盘格向导的标定自动满足矫正要求（原始帧在抓拍时实时矫正）；外部标定仍须已是矫正输出；普通原始 K/D/R/T、NPZ 标定文件或厂商专用 SDK 输出请改用内置向导，或先转换并完成校正/配准。

方向和倾斜设置修改的是整个双目组到 CAD 的刚性外参。`+X/-X/+Y/-Y/+Z/-Z` 表示相机在模型的哪一侧并朝向模型；yaw、pitch 修正未正对投影方向，roll 修正画面倾斜。调整保持左右基线长度和极线关系，参与 CAD 投影、管道角度匹配、定位、中心距/净距和前后判定，不会重新旋转图像，也不能代替双目极线矫正。

STL 没有标准单位、颜色、图层和业务 ID。程序按不连接的网格组件拆分并生成稳定组件 ID；相接或共享顶点的实体会合并。灰色占位颜色、自动外径和业务 ID 必须逐管核对，数据包会保存所选 STL 原单位并继续按毫米分析。

## 观察局部与自动判定

选择管件后，可切换左、右照片。滚轮放大缩小，按住右键平移。勾选“拖框选局部”后，用左键拖出测量范围；选区应覆盖管件两侧和一小段轴向，不需要展示整根管件长度。选区记录的是原图像素坐标，缩放不会改变位置。修改选区后需要重新运行分析；换一组照片不会自动沿用旧选区。

自动测量从两目有效深度分别拟合局部圆柱，得到观测外径、局部轴线和位置，再校验两目是否一致。CAD 仅提供目标身份和搜索邻域，拟合外径不从设计外径复制，也不受设计轮廓裁剪。当前方法针对直管局部，要求可见曲面弧度及局部长度足够；最少需要约 40 mm、且不少于两倍测得外径的轴向支持。光滑、反光、遮挡或纹理过少的表面可能缺少有效深度，这类结果显示待确认。

“逐管当前状态”分别列出安装状态、设计外径、自动外径、校正外径、外径对照偏差、轴线位置偏差与相机深度。“所选管件分析”提供局部中心 XYZ、待确认原因及与其他管件的关系。

“中心距 · 净距 · 前后”页显示每一组管件的关系，可以切换为仅显示与当前管件相关的组合：

| 项目 | 计算口径 |
|---|---|
| 中心距 | 三维局部轴距；近似平行轴采用双方观测范围的共同截面中点。斜交轴采用两轴最近点，且最近点必须位于双方观测范围内。 |
| 原始净距 | 中心距减去两管自动测得的半径之和。负值保留，用于复查碰撞或错误拟合。 |
| 校正净距 | 使用可用的校正外径重新扣除半径；未校正的管件使用原始外径。 |
| 深度差 B−A | 同一局部位置的相机 Z 深度差；正值表示 A 更靠近左相机。 |
| 前后判定 | 以左相机观察方向为准。深度差未超过对照阈值或两目位置差时，显示深度接近、待确认。 |

缺少任一管件的有效测量、没有共同可测截面、两目结果矛盾或身份冲突时，该关系不输出确定数值。管件前后层的 CAD 标签是设计属性，自动前后关系来自实际观测。近似平行指轴线夹角不超过 1°，此时净距为该共同截面的局部近似；不外推整管最小净距。

## 实测登记和二次校正

选择当前管件及项目（外径、中心距或净距）；间距还要选择另一根管件。输入卡尺/量具实测值、截面编号与备注，再选择用途：

- **登记对照**：记录实测与自动原始值，查看原始误差。
- **校正样本**：用于外径的加性偏差校正。中心距和净距可以登记、验证，当前不拟合相机位姿或空间尺度。
- **独立验证**：检验修正后的外径误差。与校正样本使用同一组照片的记录不会计入独立验证。

样本自动保存，包含管件 ID、截面、照片内容签名、标定配置、自动原始值和人工实测值。“工作簿另存”和“打开工作簿”用于携带样本继续测试。换标定配置后，旧样本不会参与新配置校正。所选管件、照片及截面对应的登记外径也会显示在照片上方。

没有有效自动测量时仍可登记实测值，但该条没有自动值，不参与校正。之后分析成功，可重新添加带自动值的样本。修改历史样本只改变实测值、用途与备注，保留原拍摄来源；删除和添加都即时保存。

当前校正取各校正样本“实测减原始”的中位数，保留原始外径，另列校正值；不更改模型、相机标定或安装状态。样本残差超阈值时暂停修正。修正只用于样本覆盖的原始外径范围（边界允许一个对照阈值），不外推至其他管径。至少来自 **3 组独立验证照片**的样本误差均在阈值内时，显示“独立样本对照通过”；这仅说明所测样本，不代表其他距离、光照、姿态或全部现场的精度保证。

尺寸/位置对照阈值默认 **±1 mm**，可修改。它用于提示观测与设计的偏差，和采样验证的误差判断；它不是相机已达到的精度，也不自动等同于施工验收公差。

## 逐管报告

点击“导出逐管状态”，选择保存目录。每次导出单独的时间目录，包含：

- `逐管分析.md`：每根管件的当前状态、测量说明和可用间距/前后关系。
- `逐管状态.csv` / `逐管状态.json`：完整逐管数据，可在 Excel 等工具查看。
- `管件间距与前后.csv`：所有管件组合的测量与待确认原因。
- `实测工作簿.json`：实测样本及设置。
- `双目原始报告.json`：与当前输入匹配的原始识别结果（存在有效报告时）。

安装状态只有“已安装、未安装、待确认”。尺寸或位置超对照阈值会单独提示偏差；看到管件并不代表尺寸合格。未观察到管件也不会直接判为未安装：当前仍要求至少两次足够间隔、内容独立且满足有效空闲空间条件的双目拍摄，遮挡和无效深度保持待确认。

## 软件验证

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m pipe_twin analyze-stereo --manifest test_model/field_stereo_demo_manifest.json --output outputs/gui_validation/stereo_report.json
.\.venv\Scripts\python.exe scripts/smoke_measurement_gui.py
```

几何测试使用独立解析圆柱与已知深度，验证观测外径不被错误的 CAD 外径锁定，并覆盖三维中心距、净距、前后反转、未知状态和无效视差。工作台配置档案测试覆盖校验、原子保存、损坏隔离和安全勾选永不落盘；棋盘格向导测试用已知内参/基线的合成刚体验证求解与矫正配方的 fail-closed 行为。真实相机的毫米精度需要按实际工作距离和遮挡情况另做实测验证。
