# 管道安装分析 GUI（2026-10-28）

双击仓库根目录的 `run_gui.bat`，或运行：

```powershell
python -m pipe_twin gui
```

现在直接进入现场分析窗口，无需再点击“基础立面评估”。主流程为 **DXF/STL 模型 → 标定 → 双目抓拍 → 管段汇聚 → 断面尺寸与重复性 → CAD 相对就位**。模型比较使用外径和管间相对距离，不要求管长，也不把相机到管道的绝对距离当作 CAD 匹配目标。

**默认启动会清空全部旧选区**：绿色管段框、橙色汇聚范围和紫色地面框均不自动沿用。模型、标定和其他设置继续载入，上次照片仅供参考；先③抓拍，再④设置本次范围。需要复盘或继续以前的范围时，手动点击“打开现场”选择历史 manifest，才会恢复其中的选区。

界面按 **①模型 → ②标定 → ③抓拍 → ④分析准备 → ⑤保存并评估** 从上到下排列。④包含下面三种不同范围；设置完再执行⑤，之后修改范围需要重新评估。

| 范围 | 框什么、做什么 | 与其他范围的关系 |
| --- | --- | --- |
| 橙色管段汇聚范围 | 沿管长拖线，在两条垂线之间累计轮廓；可保留自动方式 | 与绿色管道区取交集，不能完全错开 |
| 绿色管道评估区（可选） | 框待测管道，跨过需要比较的各管并保留完整管宽 | 不框时全图找管；不是地面选区 |
| 紫色地面选区（可选） | 框裸露地面、避开管道与支架，用于估计相机倾角 | 独立于绿框和橙色范围，可以在它们之外 |

紫框的倾角结果用于辅助管轴和断面求解，不限制去哪里找管。“倾角检查”只检查当前照片；⑤会按当前设置重新执行完整分析。同一次操作中，固定机位和相同图像尺寸下可复用范围；关闭再启动会清空选区，需手动打开历史现场才能沿用已保存范围。

如果把管道绿框误画在地面上，可用 **场景与诊断 → 恢复全图管道分析（清除评估框）**。此操作保留橙色管段范围和紫色地面选区。绿框与橙色范围完全没有交集时，主界面提示冲突，⑤会阻止无效分析；点击“重画当前区域”替换绿框。

主界面只保留**一个当前管段评估区域**，一个框可包含多根管道。重画直接替换旧框，取消或框太小则保留原框；不提供新增分区或多个区域并行。旧 Z01/Z02 是历史选区配置，不是本次测量结果。手动打开历史现场时，只沿用唯一有效区域并移除当前操作中的停用草稿；若历史中有多个有效区域，则恢复全图并提示重新框选。历史文件不改写，点击⑤另存新的现场。

## 第一次建立现场

1. 点击“①导入 STL/DXF”。默认单位为毫米；其他单位先在“设置… → 模型与范围”修改，再导入。目录显示设计管径和管号，模型管数可以多于现场实物。
2. “②标定 → 载入已有标定”选择与当前设备、分辨率及左右布局一致的标定。重新采集或检查质量用同一菜单中的“棋盘格重新标定 / 质量检查”。主界面显示质量状态、每目分辨率和基线，完整信息在“设置… → 照片与历史”。暂用标定仍明确标记为精度未核验。
3. “现场模型 / 编号 / 方向”集中显示现场相对断面和 CAD 编号，并设置模型共同管轴与相机观察侧。这是唯一的主界面模型入口；选择编号仅用于查看，不会强制建立现场对应。
4. 点击“③双目抓拍 → 打开预览”，待画面稳定后选择“多帧采集并使用”或“单帧抓拍并使用”。多帧数量可选 **10 / 20 对，默认 10 对**；慢帧率设备优先用 10 对，保持相机、管道及画面内其他物体静止。多档快门仍可调。手工导入已矫正照片、配对时间和同步确认移到“设置… → 照片与历史”。相机正常抓拍会自动记录这些信息。
5. 在主界面点“管长方向 / 汇聚范围”，沿左图管长拖一条线。两端橙色垂线之间为汇聚范围，可拖动端点调整；青色线为稳定轮廓。需要缩小整组搜索区域时使用“管道评估区域（可选）”。两者都不要求输入实际管长，手画方向也不直接替代三维管轴。
6. 点击“⑤保存并评估”。先看下方“现场求解状态”：轮廓、估计外径、连拍解出次数、重复性和对应进度。选择一行联动左右图，双击或点“查看详情 / 诊断”查看原因。在“CAD 安装状态”查看模型管位结论。报告和图像保存在新的现场目录，底部提示可滚动、复制。

⑤旁的状态摘要持续显示照片数量、重复性检查、模型观察侧、条件断面数、CAD 对应和相对就位。**采到多帧不等于多帧检查通过，断面已解不等于已可靠对应模型。** 单帧明确显示未做重复性复核，失败序列保留原因。

模型联动窗口选择观察侧后，需要点击“应用相机观察侧”。编号截面沿管轴保持固定，相机箭头联动变化；纯旋转预览不会改变匹配参数。存在未应用方向时，保存会提示先应用，或点击“恢复已应用方向”放弃该预览，不再静默清除。应用后再点击⑤更新结果。

多帧采集过程中，每成功保存一对照片都会原子更新同目录的 `capture.json`，记录实际时间、左右配对、照片哈希、标定和矫正配方。中断序列标为不完整，不自动用于评估；完成也不代表通过质量检查。此归档用于防止退出或写盘异常丢失配对证据，不自动恢复历史选区。

## 地面倾角和分析设置

需要调整相机朝向时，先进入 **地面选区 / 倾角… → 实时调姿**，启动预览，在实时左图中框选裸露、有纹理的地面。缓慢调整机位，使左右镜头光轴偏离地面法线的角度都接近 **0°**（即光轴与地面约 **90°**）。方向图按左镜头的右/下方向显示；角度接近零时不能据此确定绕地面法线的朝向。默认 **2°** 是可调整的调姿辅助范围，不是测量精度承诺。

实时预览与最近一次测角证据分开显示；地面计算每隔数秒更新，证据图、角度、帧号和采集时间属于同一对照片。停稳后等待连续有效测量进入目标范围并稳定，再停止监控。画面过暗、平面不可靠、结果过期或停止时均撤销对准状态。实时调姿只作现场辅助，不保存或覆盖原现场，也不把监控帧用于安装验收。

实时调姿通过标定配方把地面法向转换到实际左右镜头坐标，历史倾角报告则使用矫正后的虚拟光轴，两者数值可能略有不同。只有平面无法确定相机绕法线的转角或完整 CAD 位姿。调好机位后重新执行 **③抓拍 → ④设置本次范围 → ⑤保存并评估**；机位变化后旧照片和旧选区不代表当前现场。

垂直向下拍摄便于提取管道横向像素宽度，毫米直径仍依赖标定、管道距离和双目投影求解。地面距离不能直接代替管道距离；管道不必贴地，监控也不假设其安装高度。双目连线与管轴接近平行时，断面轮廓求解仍可能对边界误差敏感。

④ **机位几何检查** 打开报告中的机位页，显示物理基线、垂直管轴的有效分量及二者夹角。它来自评估照片，不是实时角度；应先评估一次。让两镜头连线更多地横跨管道，通常有利于轮廓断面求解。程序现在支持画面内任意管长方向，包括竖直；仍保留原始矫正像素坐标，不通过旋转图片冒充新的观察角度。调整后重新抓拍、画范围并评估；有效分量变大不等于精度已经合格。

“地面选区 / 倾角…”打开地面设置页：先点击“左图框选地面”，在左图框裸露地面，再回到该页执行“倾角检查”。图面显示实际支持像素与角度；“查看倾角与修正结果”打开统一报告的地面页。独立倾角检查不重算管径，重算仍需点击⑤。

图面的主角度为**光轴偏离地面法线**：0° 表示垂直看向地面；详情另列“光轴与地面夹角”，0° 表示平行地面，两者互为余角。通过地面与边界检查后，按“管轴平行地面”重新求解三维管轴及断面，允许同一管两端到相机距离不同，不要求相机正对管道。

地面通过双向图像块亚像素匹配、留出样本和左右平面检查确定；涂色仅是实际支持样本，不是补出的整块地面。若多帧失败但当前末帧双目对健康，会独立检查当前帧地面，明确显示“仅当前帧／连拍未通过”。地面通过不会恢复连拍或安装验收；候选试验开关仍控制是否作试验分析。

“试用候选地面倾角”开关仍保留，主界面会显示试验是否开启。试验允许未通过检查的有限候选用于对照，不代表相机姿态已核验，也不会直接判定安装就位。

彩色管道的外轮廓采用颜色支持与局部亚像素边界处理，减少暗外缘和彩噪干扰；白色管的中性阈值路径保持独立。黄色框仅表示颜色候选，青色分段表示通过检查的观测边界，缺失列不连接。旧报告缺少逐列支持记录时需重新评估才能显示新版边界。颜色边界稳定不等于半径、深度或 CAD 对应已可靠。

主界面将“平面检查通过/未通过”和“修正实际应用/未应用”分开显示；“试验已应用，未验证”不能当作地面解算合格。地面详情列出有效深度、平面与留出一致率、实际残差及门限。未配对断面详情会说明稳定边界数、宽度冲突等原因；仅有两条独立轮廓时不足以自由求解圆心和半径。

| 设置页 | 功能 |
| --- | --- |
| 照片与历史 | 导入矫正图、同步时间/确认、沿用历史、完整标定信息 |
| 模型与范围 | 原始单位、现场实物数量、当前范围、清除当前区域、观察侧 |
| 求解参数 | 辅助识别方法、弱光降噪、视差范围、直径/颜色容差、颜色与反光检查 |
| 地面修正 | 地面选区、独立倾角检查、候选倾角试验、修正报告 |

设置窗口不占用主界面照片区域；分析期间输入控件暂停修改。改变输入会清除旧报告，需重新评估。颜色编辑按钮只在“CAD 安装状态”页出现，颜色筛选默认关闭。

## 新增管道后的状态刷新

固定机位下安装新管道后，打开同一个现场，正常执行③抓拍和⑤评估；也可用“场景与诊断 → 重新抓拍并评估”：

1. 客户端重新打开双目抓拍，等待画面稳定后完成新的一对同步照片。
2. 程序追加新的 capture group，沿用模型、管道目录、标定和历史照片，不覆盖旧证据。
3. 程序自动重新计算局部深度、直径、立面相对布局和三态结果。报告记录刷新请求时间、左右目拍摄时间和分析完成时间。

## 自动识别和证据

现场工作台不提供逐管拖框、二维码定位或手工观察到模型的绑定。照片中的证据框由算法生成，右键平移、滚轮缩放用于查看。颜色配置只用于模型属性和可选辅助筛选。求解参数页保留自动、仅双目深度几何、图像引导圆柱和平行局部条带等辅助后端；匹配策略保存在 `analysis.matching`。管段汇聚和断面求解有独立报告，不应混淆二维边界稳定、条件尺寸解出与三维安装验收。

报告会把每根模型管标记为 `INSTALLED`、`NOT_INSTALLED` 或 `UNKNOWN`。双目左右不一致、有效深度不足、局部被遮挡、直径超出模型范围或存在多个相近布局时，结果保持 `UNKNOWN`，不会用颜色单独给出确定身份。未安装判断还需要连续独立采集的可靠空位证据。

## 标定复用边界

重新标定入口是 **②标定 → 棋盘格重新标定 / 质量检查**。顶部显示棋盘格长、基线和分辨率；需要修改时点“展开参数 / 相机设置”。本现场为 **9×7 方格（8×6 内角点）、实测格长 17 mm、镜头中心距 60 mm、每目 1920×1080**。

点“打开预览”，保留“连续抓拍”勾选。左目叠加 1～9 九宫格，与上方区域图一一对应；按**棋盘角点中心**确定所在格，整个棋盘仍需同时完整出现在左右画面中。任意顺序移动棋盘，不必照编号顺序。

- **灰色 / 待采集**：该区域尚无保留的照片组。
- **黄色 / 秒数**：当前区域正在停稳检测。两眼均完整检出、清晰度满足门限后开始计时；至少稳定 6 秒、通过至少 3 次检测才采集，通常约 6～10 秒。计时只随实际检测更新，不在相机或检测停滞时自行走完。移动、切换区域、丢失角点或清晰度不足会重新计时。
- **绿色 / 已采集 N 组**：已有成功采集且保留的双目照片。变绿后可以移动到灰色区域；同一格内还可改变远近或倾斜补拍，原地不动不会不断重复自动采集。移除照片会同步更新绿色状态；停止预览只清零计时，保留已采集记录。手动模式下计时完成后需点“抓拍一组”才计入。

九宫格绿色表示**位置覆盖**，不表示标定已经通过。仍需改变远近、前后与左右倾斜，建议保留 20～30 个不同姿态；确实无法覆盖的角落不必勉强塞入而裁掉棋盘，覆盖门限仍由求解器检查（至少 6 区）。最后点“完成标定并保存”，通过训练检查和留出验证后才保存新标定，再用独立实测尺寸验收毫米尺度。

点击完成后会停止预览并在后台解算，期间暂时锁定采集和参数，窗口仍可响应。结果分别显示**照片 / 区域覆盖、联合优化是否收敛、留出验证误差**。照片数量充足但验证误差超限时，会列出误差、门限及本次输入照片组号；按具体失败项检查，不能把这类问题理解为单纯少拍了几张。关闭窗口会放弃应用尚未返回的后台结果。

同一台相机、镜头、分辨率、裁剪和左右布局下，已通过 `validated=true`、`rectified=true` 门禁的标定可以反复使用，不需要每次抓拍前重新标定。更换上述图像几何条件或发现极线/深度质量失效时，才重新运行棋盘格向导。原厂资料目录 `doc/双目测距、深度图、标定代码/` 只作为参数和格式参考，不会被现场程序直接执行。

## 日志和现场文件

CLI、GUI、抓拍和识别都会写结构化 JSONL 日志：

```text
logs/pipe_twin.log.jsonl
```

现场包至少包含 `manifest.json`、左右照片哈希、模型副本、识别报告、`surface_audit` 和算法生成的证据文件。照片素材可以留在现场证据目录，不需要提交 Git；功能代码、配置格式和测试应提交 Git。

## 当前清理边界

- 现场工作台和现场数据包只接受 DXF/STL 自动立面；旧 `elevation_depth` 逐管区域包会被拒绝。
- 3DM/3MF、二维码绝对配准和逐管手工框选已从现场操作入口移除。仓库中保留的旧解析器和合成资产只服务离线回归，不属于当前现场输入。
- 当前 GUI 使用全图或单一管段区域，右目搜索范围按视差边界自动扩展；不提供多区域并行，也不把整组区域当作单根管道身份。旧多分区数据格式和算法仅保留供历史离线复盘。

## 软件验证

```powershell
python -m pytest tests -q
python -m compileall -q pipe_twin
```

真实相机的毫米精度仍需在现场有照明、左右目同时看到连续管道侧面的条件下复核；合成回归只验证软件链和安全门禁。
