# 相机从立面的哪一侧看

已知拍摄侧时建议指定；不知道模型坐标与现场的对应关系时，保留 **自动判断（未指定）**。程序原本就会搜索观察姿态，但相同管径、对称排列或可见管道较少时，可能有多个成立的方向。指定观察侧可排除相反方向的候选，不会代替双目观测或相机标定。

## GUI 操作

1. 在 **基础立面评估** 导入 STL/DXF，找到 **相机从哪侧看（模型坐标）**。
2. 点击 **查看方向示意** 或 **查看模型管道编号**，两个入口打开同一个联动窗口：左侧是三维方向，右侧是沿共同管长轴观察的编号截面。核对两侧的模型 X/Y/Z 坐标轴。
3. 下拉选择一个相机观察侧，左侧预览正对该侧，右侧相机箭头同步显示视线投影；截面保持固定。点击 **应用相机观察侧** 保存，窗口保持打开。也可直接在主窗口选择观察侧，两边同步更新。
4. 核对左右照片，点击 **保存并评估**。固定机位后可复用；改变方向会清除旧结果、断开旧历史。换模型后恢复自动判断。

| 选择示例 | 含义 |
| --- | --- |
| 从 +X 侧朝 -X 看 | 视线在模型坐标中朝向 X 减小的方向 |
| 从 -Y 侧朝 +Y 看 | 视线在模型坐标中朝向 Y 增大的方向 |
| 从 +Z 侧朝 -Z 看 | 视线在模型坐标中朝向 Z 减小的方向 |
| 自动判断（未指定） | 不施加观察侧限制，依靠实际双目几何求解 |

这里的“侧”以**模型坐标**为准，不等于照片左侧/右侧，也不是办公室东南西北。未约定模型轴时，不能仅凭一张照片确定应选哪个符号。模型预览中的右键旋转不会写入观察方向；只有下拉选择并应用才会保存。

点击三维管线、截面圆或编号，两个视图和主窗口管道列表会同步高亮同一根管；直接在主列表选管也会同步。三维投影重叠时可重复点击切换，或在截面图直接选管。下方显示所选管的模型外径和颜色。这里的选择仅用于浏览，不创建照片与模型的身份对应，也不会修改评估结果。

右键旋转和滚轮缩放只作用于三维预览，截面保持从共同管长轴的正侧向负侧看。切换相机侧只更新箭头；只有改变管长轴的正反向才会相应翻转截面，标题会显示轴向量。沿管长端面观察时用“朝纸内/朝纸外”文字说明，不绘制不存在的平面箭头。相机箭头只表示方向，不表示机位或距离。

**管长方向是另一项设置。** 当前圆形 DXF 把圆心放在 XY 平面，管长沿 Z。因此 ±Z 是沿管长端面看，±X/±Y 是从管道侧面看；不能因为文件叫“立面图”就固定选择 +Z。STL 的坐标取决于建模文件，用模型坐标轴核对。

## 对分析结果的影响

观察侧是半空间限制，允许斜视。它不指定相机位置、滚转角、精确倾角或到管面的距离，不要求相机与立面垂直。方向变化不会重算相机内参标定。沿管长的绝对位置仍不可观测。

候选旋转把模型转换到左目矫正相机坐标后，所选侧向量必须朝相机方向（相机 -Z）。若方向正好与视线垂直，无法确认这个观察侧；若方向相反，该候选被排除。所有几何候选都被排除时，报告原因 `CAMERA_SIDE_CONFLICT`，GUI 显示“所选相机观察侧与双目几何冲突”，安装状态仍为 **遮蔽不确定**。先核对所选侧，也应检查局部观测和模型；该原因不能单独证明操作员选错了。

自动识别所需的观测数量、非退化布局、管径/残差和搜索上限不变。方向正确也可能继续不确定；它不能补出被遮挡的管道。颜色与反光检查仍是独立的拍摄调整工具。

## 保存与远程重算

`analysis.elevation_auto.registration.camera_side_world` 保存模型朝向相机观察侧的单位向量；例如 `[0,-1,0]`。旧包没有此字段、或显式 `null`，都按自动判断兼容。全幅和分区分析使用同一全局观察侧。

报告的 `registration.camera_view`（分区时在逐区配准审计中）记录用户方向、策略 revision/hash 和被拒绝的候选次数。策略版本 `camera-side-hemisphere-v1`，要求朝向余弦严格大于 `1e-6`。成功配准及备选姿态的 `estimated_camera_side_world` 是实际求解的光轴反方向，仅 `MATCHED` 的姿态可用于后续判断；它不是测得的相机绝对位置。

本功能的软件回归不等于现场精度验收。现场未确认朝向前，请保留自动判断，不根据旧照片猜测方向。
